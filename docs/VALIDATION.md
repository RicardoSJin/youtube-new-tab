### 自动化回归（47 / 47 通过）

运行 `npm test`，在 jsdom 中执行扩展源文件，后台 `chrome.*` API 使用模拟器：

- 两套实测结构的标题、封面及嵌套元素点击：每次一次 sendMessage、一次 tabs.create，站点事件处理未到达，源 URL 不变。
- 普通视频保留时间戳、播放列表上下文与参数。
- Enter、form 外执行按钮、submit 回退；中文、加号、& 编码。
- Enter／点击后紧接 submit 的重复链只创建一次；长按 Enter 和双击不重复。
- 连续独立操作不被粗暴时间节流丢弃。
- Ctrl / Shift / Alt / Meta、非左键、auxclick、contextmenu、修饰搜索及后续 submit 不拦截。
- 频道、菜单、稍后观看、广告观看、展开搜索、清空、建议选项不拦截。
- 播放列表卡片的 watch 标题／封面不拦截；`/playlist`、Shorts、live 路由、无效 ID、外部域名不拦截。
- 开关独立、设置变化自动应用、active=true / false 传给 tabs.create。
- 模拟 history.pushState、搜索框整体替换、追加卡片、脚本重复执行后行为保持且无重复监听。
- 空搜索、输入法组词、无关表单排除。
- 创建失败／消息失败保留源 URL，不重试并显示提示。
- 后台校验请求来源、顶层 frame、目标 URL 和当前设置。
- 设置 UI 默认值、修改、持久化重开和保存失败回滚。

这组测试证明模拟环境中的事件、消息和参数行为，**不验证真实浏览器焦点、真正的新标签页数量或音视频状态**。

## Chrome / Edge 人工验收步骤

请在每个浏览器分别执行，安装后先刷新 YouTube：

1. 默认配置下，在首页、搜索结果、频道页、订阅页、播放页推荐区各点击一次标题、一次封面。每次只增加一个标签；源 URL 不变，当前激活新标签。记录页面类别及浏览器版本。
2. 播放一个视频，记下进度。在顶部输入新的关键词，按 Enter。只新增一个搜索结果标签；返回原标签，确认原 URL 与播放器仍在，进度正常推进。
3. 换另一个关键词，点击执行搜索按钮，重复步骤 2。窄窗口须先展开搜索框，展开动作本身不得开页。
4. 在扩展设置选择“留在后台”，重复视频、Enter、按钮三种操作。每次只新增一个后台标签，原标签保持激活。
5. 分别关闭“视频”和“搜索”，验证两个开关独立，关闭项恢复 YouTube 原生行为。
6. 保持扩展启用，点击站内频道／首页导航（不刷新浏览器），再执行视频和搜索操作；继续滚动加载更多视频后再点击，检查无失效或重复创建。
7. Ctrl / Shift / 中键 / 右键菜单分别操作视频。比较扩展禁用时的行为，确认一致；菜单、稍后观看、频道和播放列表卡片不被拦截。
8. 中文输入法组词时按 Enter 确认候选，不应开搜索页；完成输入后再次按 Enter，应只开一个搜索页。空白输入不打开标签。

若发现不符合预期，请记录上述步骤、浏览器版本、开关状态、页面类型和有关元素最小 outerHTML，不需提供 Cookie、完整页面源码或账号数据。
